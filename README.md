# docs

个人技术文档仓库，用于沉淀日常开发中的各类文档。

按主题分篇存放，内容持续补充，不限于某一领域。

---

## 文档清单

### [项目初始化指南](项目初始化指南.md)

各语言与框架的脚手架选型与验证链配置。

- 前端 13 个框架、后端 9 类语言的初始化命令
- 每个框架自带哪些 lint / 类型检查 / 测试
- 组合配方、验收清单与常见坑

适合：新项目选型、团队技术栈落地。

### [AI 初始化指南](AI初始化指南.md)

给项目接入 AI 编码代理的完整流程。

- AI 文档的五层组织模型
- 主流工具的入口文件、配置与 MCP 接入

适合：给已有或新建项目补充 AI 协作规则。

## 阅读约定

| 标记 | 含义 |
| --- | --- |
| ✅ | 该命令已在编写时实测跑通 |
| 无标记 | 官方标准命令，未在本机验证 |
| ⚠️ | 容易踩的坑或版本差异 |

- 命令以官方最新稳定版为准，执行前建议先看 `--help`。
- 每篇文档头部标注更新日期，过期内容以官方文档为准。

---

## 新增文档

1. 在仓库根目录新建 `<主题>.md`，文件名即标题。
2. 在上方「文档清单」中追加一条：标题、链接、一段简介。
3. 文首写明更新日期与相关文档的跳转链接。
4. 涉及命令的内容尽量附可复制的完整写法。
